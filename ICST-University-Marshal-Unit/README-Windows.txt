ICST University Marshal Unit — Windows x64, version 1.2

1. Extract this folder to a permanent, writable location on your computer.
2. Double-click ICST-University-Marshal-Unit.exe.
3. The application opens in your default browser. Keep the application
   console open while using it. Close the console or press Ctrl+C to stop.

Node.js, the interface, and the local service are built into the EXE.
No separate Node.js installation or internet connection is required.
The application runs only on this computer at http://127.0.0.1:4173/.

DATA
Records, photographs, attachments, accounts, and audit history are saved
in data\icst-marshal.sqlite beside the EXE. Keep the entire data folder
beside the EXE when moving or updating it. A new EXE in a different folder
starts a separate empty installation. Software downloads contain no
private accounts or records.

To continue an existing installation, place this EXE in the same folder
as its existing data folder, or move both the EXE and complete data folder
together after stopping the application.

ACCOUNT AND BACKUP
On a fresh installation, create your Marshal account with your university
email and an application password of 12–128 characters.
Use Settings to change your application password or download a backup.
Your university manages the email mailbox password itself.

BACK
Each main page has a Back button that returns to the previous page while
preserving searches, filters, views, and record tabs. On the first page,
Back is disabled. Forms and case dialogs also have a Back button.

RECOVERY
Use Reset Password.cmd beside the EXE for masked local password recovery.
Alternatively run ICST-University-Marshal-Unit.exe --reset-password.

This portable build is unsigned. Open-source notices are available from
the application footer and included in the licenses folder.
